# Rahul Patil | Portfolio

A minimal, dark-themed personal portfolio of **Rahul Patil**, an AI & Data Science student at VIT Pune who is learning to build useful things with code.

🔗 **Live site:** `https://rahulpatil00271-svg.github.io/rahul-portfolio/`

## ✨ About

This portfolio documents my tech journey: strengthening programming fundamentals, exploring AI and development, and growing through content creation and fitness.

## 📌 Sections

- **Home**: Introduction and quick links
- **About**: A little about me and my journey
- **Focus**: What I'm currently exploring
  - Code & AI: Python and programming fundamentals
  - Content & Editing: short-form video editing
  - Fitness & Discipline: calisthenics and consistency
- **Connect**: Social links

## 🛠️ Tech Stack

- HTML5
- CSS3 (custom properties, Grid, Flexbox, responsive design)
- No frameworks, no dependencies, just a single `index.html`

## 🚀 Run Locally

```bash
git clone https://github.com/rahulpatil00271-svg/rahul-portfolio.git
cd rahul-portfolio
```

Then open `index.html` in your browser.
